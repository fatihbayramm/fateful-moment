# Screenshots

Drop your captures here — the README references these exact filenames and will render them
automatically. Use the same filename for both platforms where the screen is identical.

**iOS** (`ios-*` prefix)

| File | Screen |
| :--- | :--- |
| `ios-welcome.png` | Welcome |
| `ios-register.png` | Register |
| `ios-login.png` | Sign in |
| `ios-reset-password.png` | Check your email |
| `ios-scenarios.png` | Scenario list |
| `ios-scenario-detail.png` | Scenario briefing |
| `ios-scenario-options.png` | Decision options |
| `ios-decision-dna.png` | Your Decision DNA |
| `ios-menu.png` | Menu |
| `ios-settings.png` | Settings |

**Android** (`android-*` prefix) — same list, same filenames.

### Tips for clean captures

- **iOS:** run on the iPhone 16e simulator in landscape, then `Cmd+S` to save the window
  (or `xcrun simctl io <udid> screenshot`).
- **Android:** run on an emulator in landscape, capture with `adb exec-out screencap -p > file.png`.
- Crop out the device bezel — the README already frames the images in a table.
- Keep them under ~400 KB each so the README stays fast.
